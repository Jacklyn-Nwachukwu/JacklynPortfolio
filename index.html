About

I'm a frontend developer with a passion for building intuitive, performant, and visually compelling digital experiences. I believe the best interfaces are those that feel effortless to use and beautiful to look at, and I pursue that balance in everything I build.

My work spans everything from redesigning iconic interfaces to building practical tools people use every day. I've recreated the Google homepage, crafted a polished clone of the ALAT by Wema banking homepage, and built a clean, fully functional To-Do list app, each project sharpening my eye for detail, layout, and usability.

I'm comfortable working across the full frontend stack, from semantic HTML and responsive CSS to React components and TypeScript. I care deeply about writing code that is not just functional, but readable, scalable, and accessible to everyone.

When I'm not building things for the web, I'm exploring new design trends, learning something new in the JavaScript ecosystem, or enjoying a good read.
